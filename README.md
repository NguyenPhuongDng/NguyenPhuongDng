## Selected projects

### [VLens — Multimodal Traffic Incident Analysis](https://github.com/NguyenPhuongDng/Vlen)
**AI Engineer · Team of 4**

An AI agent that analyzes dashcam videos and vehicle logs, extracts timestamped evidence, and generates incident reports.

- Improved incident recall from **57.69% to 96.15%** through verification and targeted re-analysis.
- Achieved **98.04% F1** at an average cost of **$0.0043 per sample** on a **38-sample benchmark**.
- Integrated human review, PostgreSQL persistence, Redis caching, and LangSmith tracing; containerized with Docker for AWS deployment.

`Python` `LangGraph` `Qwen-VL` `FastAPI` `PostgreSQL` `Redis` `LangSmith` `Docker` `AWS`

### [SEA AI Translation — Multilingual Machine Translation](https://github.com/NguyenPhuongDng/AI-Tranlator)
**Individual project · Research & application**

An end-to-end translation project combining multilingual model adaptation, data quality engineering, and a web application.

- Reported improvements of **+9.21 SacreBLEU** and **+6.3 COMET** across **9 Asian languages** using NLLB-200-3.3B, parameter-efficient SFT, CPO-SimPO preference optimization, and pivot translation.
- Built an **8-stage data quality pipeline**, including MinHash LSH deduplication and LaBSE semantic filtering on ALT and FineTranslation data.
- Shipped a Flask/PyTorch application with speech-to-text, text-to-speech, sliding-window processing, and a feedback collection loop.

`Python` `PyTorch` `Transformers` `NLLB` `vLLM` `Flask` `Docker`
